Mis proyectos

Estos son algunos de los proyectos en los que he trabajado para poner en práctica mis conocimientos de programación. Incluyo trabajos universitarios en equipo y una iniciativa personal que estoy comenzando a desarrollar.

Zona Bikers

Proyecto universitario en equipo · Versión inicial completada

Sitio web de una tienda de accesorios para motocicletas, con páginas de catálogo, detalle de productos, carrito y administración.

Mi aporte: Desarrollé la lógica en JavaScript para validar formularios, registrar usuarios y gestionar el inicio de sesión. También implementé las funcionalidades del carrito de compras, incluida la incorporación de productos.

  • Tecnologías: HTML5 - CSS3 - JavaScript
  • Próxima etapa: Migración de la interfaz a React.
Ver repositorio de Zona Bikers

TacticalTrack

Proyecto universitario en equipo · En desarrollo

Aplicación móvil orientada al registro y verificación de visitas en terreno a equipos de refrigeración. Incluye registro de evidencia fotográfica y ubicación GPS para facilitar el seguimiento de las visitas.

Mi aporte: Implementé la captura de fotografías, la obtención de ubicación GPS y el registro de evidencia de las visitas. También desarrollé la validación de visitas por un supervisor e integré el flujo de navegación de la aplicación.

  • Tecnologías: Kotlin, Jetpack Compose y Android Studio
Ver repositorio de TacticalTrack

TechStore API

Proyecto universitario

API para gestionar productos de una tienda mediante operaciones de registro, consulta, actualización y eliminación. Desarrollada con Java y Spring Boot, con una integración de PostgreSQL y configuración para contenedores Docker.

  • Tecnologías: Java, Spring Boot, PostgreSQL y Docker
Ver repositorio de TechStore API

Aplicación para entrega de insumos

Proyecto personal · En planificación

Proyecto que surge de una necesidad de la bodega de mi trabajo. Su objetivo es registrar la entrega de insumos a técnicos y generar un comprobante PDF con sus datos, firma y detalle de la entrega. Contempla consultar el inventario de la empresa mediante Odoo.

Mi avance: Definí el objetivo y las funciones principales. Realicé pruebas básicas de formularios en Python y estoy preparando el inicio del desarrollo móvil en Kotlin.

  • Tecnologías previstas: Kotlin

Conocimientos aplicados

  • Oracle SQL y PL/SQL: creación de consultas y desarrollo de programas y paquetes para organizar lógica en la base de datos.
  • HTML: estructuración de páginas web con etiquetas semánticas, encabezados, navegación y enlaces.
  • CSS: aplicación de estilos para definir la presentación visual de páginas web.
  • JavaScript: implementación de validación de formularios, registro de usuarios, inicio de sesión y lógica del carrito de compras en Zona Bikers.
  • Kotlin y Jetpack Compose: creación de pantallas e interfaces para aplicaciones Android en proyectos académicos.
  • Java y Spring Boot: desarrollo de APIs en proyectos académicos con arquitectura monolítica y de microservicios.
  • React: creación de interfaces web organizadas en componentes, mediante ejercicios académicos de carrito de compras.
  • Python y pandas: lectura de archivos Excel, manipulación de DataFrames y elaboración de tablas de frecuencias para ejercicios de análisis de datos.

Sobre mí

Disfruto programar y aprender durante el proceso, especialmente cuando descubro formas más claras y eficientes de construir una solución. De mi experiencia en mantenimiento de ascensores llevo al desarrollo el pensamiento crítico, la perseverancia y la atención al detalle. Me gusta concentrarme en lo que estoy construyendo y seguir buscando alternativas cuando algo no funciona.
